# Week 2 Day 5 Lab 3

## Scripts

fm_tool.sh
- Finds files by pattern and age
- Can archive or delete them
- Supports dry-run and retention

proc_watch.sh
- Monitors processes
- Logs CPU and memory usage
- Can kill processes if limits are exceeded

backup.sh
- Creates timestamped backups
- Verifies archive integrity
- Applies retention policy

log_parse.sh
- Parses logs (nginx or syslog)
- Extracts top programs and error times

## Observations

The scripts automate common system administration tasks such as:
- file management
- process monitoring
- backups
- log analysis

The logs were generated in lab7-outputs and confirm correct execution.
